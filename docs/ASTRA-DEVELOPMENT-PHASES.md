# ASTRA DEVELOPMENT PHASES — CANONICAL WORKING ROADMAP

This document preserves the exact six-phase development framework being used for ASTRA OS Development.

## Phase 1 — Stabilize

- Voice: speaking gets the same response as typing
- Backtest trades genuinely save and remain after refresh
- Journal correctly separates Live / Demo / Backtest
- All pages load
- All visible buttons work
- No duplicate handlers or conflicting modules

## Phase 2 — ASTRA Trading System

- Your personal trading rules stored in ASTRA
- JEAFX-inspired framework you've personally adopted
- Market structure
- Liquidity
- Supply/demand and key areas
- Top-down analysis
- Confirmation
- Invalidation

## Phase 3 — Narrative Engine

- Context
- Market narrative
- “If this, then that” scenarios
- Alternative scenarios
- Clear no-trade conditions
- Final action: trade / wait / stay out

## Phase 4 — Mentor Mode

- “I'm going to do top-down analysis” starts the session
- ASTRA says it's ready
- ASTRA stays quiet while you analyze
- ASTRA does not interrupt
- “I'm finished” triggers review
- ASTRA checks what you said against the shared chart
- ASTRA points out missing liquidity, structure, or rule violations

## Phase 5 — Memory

- Save live trades
- Save demo trades
- Save backtest trades
- Save lessons
- Track repeated mistakes
- Use past mistakes in future coaching

## Phase 6 — Mindset

- Think and Grow Rich journey
- All 14 chapter takeaways
- Your definite chief aim
- Daily statement
- Connect mindset lessons to trading coaching

---

## Current position

ASTRA is currently working through the trading/mentor portion of this roadmap. The immediate implementation focus is VEGA Top-Down Mentor Mode and its Weekly → Daily progression.

The six phases above are the project-level roadmap. Technical implementation phases (such as Phase 2 Core Reliability & Intelligence) are subordinate engineering milestones and must not replace this six-phase product roadmap.

## Continuity rule

When discussing “the phases” of ASTRA development, use this six-phase roadmap unless the conversation explicitly asks for a technical engineering phase.
